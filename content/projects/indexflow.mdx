IndexFlow lets a Discord community owner index the server's threads and make them searchable from the open web. Questions and answers that would otherwise stay locked inside Discord get a public page of their own.

A bot indexes questions and answers from the server, and each one becomes a web page. Owners can anonymise posts, log activity through webhooks, and use the API endpoints for their own tooling. It can be self-hosted, so the data stays yours.

Built with Next.js, Hono, Prisma, Supabase, Better Auth and discord.js. Licensed under AGPL-3.0.
